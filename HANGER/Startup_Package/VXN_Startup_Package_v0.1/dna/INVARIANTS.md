# VXN Invariants v0.1

1. Human remains final authority over irreversible actions.
2. Semantic meaning is independent from a single runtime backend.
3. Deterministic work must not require an LLM in the execution hot path.
4. Validation precedes execution.
5. Evidence beats self-reported completion.
6. Capability activation must be explicit and inspectable.
7. Core remains small; replaceable capability lives behind contracts.
8. Existing languages/runtimes remain compatible via adapters.
9. Source facts and derived interpretations remain distinguishable.
10. A backend may report unsupported; it must never fake success.
