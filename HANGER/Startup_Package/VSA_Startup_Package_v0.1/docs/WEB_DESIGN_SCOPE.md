# Web / Designer scope

VSA must support:
- static homepages
- dynamic homepages/sites
- Web apps
- responsive visual editing
- code view
- live preview
- DOM/component tree
- CSS/layout inspector
- asset operations
- simple web-oriented image/vector editing
- Figma/XD-like design canvas
- Dreamweaver-like visual/code/live relationship
- FileMaker-like direct data binding
