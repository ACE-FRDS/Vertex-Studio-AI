# DNC — Dynamic Native Code

DNC is a Vertex inheritance/execution-DNA layer.

It carries structure, semantics, system logic, invariants, UI contracts,
capability contracts, execution contracts, continuity bindings, and the
rules required for a Vertex project to inherit and grow without depending
on one LLM's memory or generic software conventions.

DNC does not replace VCC.

- VCC preserves model-independent continuity/history/reasoning.
- VSP preserves disposable current state.
- DNC carries inheritable executable/structural identity.
- VXN shortens the distance between intent and execution.

Canonical principle:

> DNC allows Vertex to inherit and grow. VXN shortens the distance and accelerates execution.
