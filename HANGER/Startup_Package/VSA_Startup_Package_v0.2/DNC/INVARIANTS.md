# VSA Invariants v0.1

1. Human final authority for irreversible architecture/security decisions.
2. AI suggestions never silently override explicit Human UI/UX changes.
3. AI Memory and Studio business/solution data are separate domains.
4. Developer Workspace and Studio Workspace remain distinct concepts.
5. Core remains small; volatile capability belongs behind registries/contracts/cartridges.
6. Deterministic work must not require an LLM in the hot path.
7. Build/test/runtime evidence outranks agent self-report.
8. Past unreproduced failure is not a current blocker.
9. Source facts and interpretations are distinct.
10. Every major startup package records its lineage/version.
11. Frontend/backend is not the primary Human-facing abstraction.
12. Capability placement may vary by Browser/Desktop/Server/Edge.
13. VSA must remain useful when cloud AI is unavailable.
14. RPG presentation may be disabled without changing underlying architecture.
