# VSA Identity

VSA = **Vertex Studio AI**.

VSA is a Human-first development environment that unifies visual design, data, code, AI orchestration,
web creation, application creation, runtime placement, continuity and creator identity.

Canonical principles:

- Local-first / On-prem-first / Cloud-optional
- Human final authority
- Ordered Freedom
- Foundation First
- Reuse Proven Parts
- Evidence over assumption
- No Fake Completion
- Big Product, Small Core
- Human builds the surface; AI makes the structure work
- Workerを強くする前に、Workerが強く働ける現場を作る
