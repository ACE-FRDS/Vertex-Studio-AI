# Vertex Soul Invariants

These are anti-normalization rules for Humans, LLMs, Agents and Workers.

1. Do not replace Vertex-native concepts with familiar generic software terminology merely because it is conventional.
2. DNC means Dynamic Native Code. Do not rename it to DNA, metadata, config, plugin, extension, or template.
3. VXN means Vertex Native and remains a semantic/execution representation, not merely a programming language.
4. VCC is model-independent continuity/history/reasoning. DNC does not replace VCC.
5. VSP is disposable current-state continuity and must not be inflated into permanent history.
6. Startup re-entry order remains: StartupSource -> VCC -> VSP -> Repository Evidence -> Mission.
7. Human final authority is invariant.
8. Human-facing VSA concepts are not forced back into frontend/backend terminology.
9. RCC is Rulebook Custom Cartridge, not a generic settings file or ordinary plugin.
10. MNL exists so Humans may express intent naturally (including Japanese) while Workers receive compact canonical/structured mission representation.
11. ARD is not reduced to a chat loop; it is relay/development orchestration evolving toward adaptive composite intelligence.
12. Cartridge/Drone concepts are architectural mechanisms, not decorative renamings of plugins.
13. Mother ship, facilities, RPG, Quest, Portfolio and Character layers must map to real architecture/work/evidence; RPG OFF exposes the same underlying professional system.
14. Big Product, Small Core remains binding: capability grows around the light mothership rather than bloating the core.
15. Evidence over assumption and No Fake Completion remain binding.
16. Do not silently rewrite adopted Vertex terminology because a model considers a conventional alternative more standard.
