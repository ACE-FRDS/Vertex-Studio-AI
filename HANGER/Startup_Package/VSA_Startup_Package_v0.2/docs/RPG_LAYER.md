# Playable Architecture

The RPG layer represents real architecture:

- Mother ship = VSA
- Party = Models/Agents
- Quest = Mission
- Equipment = Model/Tool/Runtime
- Tactical book = RCC
- EXP/Status = Observatory evidence
- Hangar = Agent/Drone staging
- Catapult = Dispatch
- Dock = Build/Repair
- Warehouse = Assets/Packages
- Library = VCC/Knowledge

RPG OFF must reveal the same underlying product as a professional IDE.
