# Vertex Design Canon — Asset Circulation

## Core chain
VUR -> VVE -> Emulator/VPSF -> Safe Promote -> Real Repository

## Canonical mapping
- project_vault: project-level durable ownership / storage concept
- virtual_workspace: evolves into VVE
- cartridge_bay: detachable deployable packs
- convergence: legacy/external intake and fusion
- repository: semantic and confirmed repository world
- simulator: validation / world / emulator execution
- hub: routing and aggregation
- supply_ship: VUR distribution
- escort_ship: sandbox / workspace guard / isolation
- aegis_ship: policy / authority / anomaly / abort
- nerve_engine: event bus and inter-system messaging

## New names
- VUR: Vertex Unit Repository
- VVE: Vertex Virtual Explorer
- VCell: smallest reusable functional cell
- VCRAS: Vertex ChatGPT Remote Agent System
- VCG: Vertex Command Gateway
- VPSF: Vertex Prototype Simulation Field
- VPB: Vertex Project Beacon
